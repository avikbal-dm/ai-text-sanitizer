AI Text Sanitizer

Five tools for pasted text: clean hidden characters, review prose against a named style ruleset, compare it with your writing voice, check overlap with supplied sources, and run publication-readiness checks. Everything runs in your browser — no uploads, no accounts, no network requests.

Tool
This is an editing tool, not a detector beater. Writing to beat a classifier is the wrong target, and the ruleset behind this tool is emphatic about it. Detectors disagree with each other, they misfire on perfectly human paragraphs, and optimising for a green light drags prose somewhere worse than where it started. So the number below is style debt measured against a published set of rules and nothing else. It does not predict what any detector will say, and no tool running on your own machine can tell you that.

How this score is calculated

Every finding costs points by severity (high 3, medium 1.5, low 0.6) multiplied by confidence (certain 1, likely 0.85, heuristic 0.6). Those are summed into a debt figure, divided by max(words, 250) and scaled to 1,000 words, then run through score = 100 × e^(−debt/100). The 250-word floor stops a single flagged word in a short paragraph from reading as a catastrophe. Every 69 points of debt per 1,000 words halves the score. That is the entire formula — there is no model and no hidden weighting.

It measures how much this text disagrees with one specific style guide. A low score on deliberately formal or technical writing may be correct behavior rather than a problem with your text. Filters below let you switch off any rule family you disagree with, and the score updates to match.

      What this tool does and doesn't do.
      
    
        
  • It does remove invisible characters (zero-width spaces, bidi controls, Unicode tag characters) that break formatting, search, and diffs — and that are sometimes used to smuggle hidden text into a document.
    • 
        
  • It does normalize the mechanical tells a machine draft carries: typographic punctuation, Title Case headings, decorative emoji, and the chat boilerplate that survives a copy-paste. Those are formatting, so they can be fixed exactly and counted exactly.
    • 
        
  • It does not defeat AI-content detectors. Those judge statistical patterns in word choice and sentence structure, not punctuation or hidden characters, so none of this changes their verdict.
    • 
        
  • It does not rewrite your prose. There is no humanize button here. The one lexical pass applies only swaps the ruleset calls unambiguous, the way a linter autofix does, and everything that needs judgment is left for you in Style review.
    • 
        
  • It does not check or launder plagiarism. If you used someone else's words or ideas, quote and cite them.

      Humanizing means sounding like you, not sounding un-machine-like.
      There is no generic human register to aim for, so the only durable target is your own.

      those samples outrank every default in it, because a set of rules is a floor for clean
      writing rather than a substitute for a voice that already exists. Paste writing you know
      is yours, then check a draft against it, feature by feature.

      The checks an editor runs before a piece ships.
      Style review asks whether the prose reads well. This asks whether it is safe to publish:
      are the figures sourced, is the drafting scaffolding gone, does the outline hold, and does
      it satisfy the brief. The unsourced-figure check matters most — a model will produce a
      confident, entirely invented 73% without hesitating, and an invented statistic
      is how a piece gets retracted.

      This is a citation aid. It is not a plagiarism checker and cannot be used as one.
      It compares your draft only against sources you paste in, and finds word sequences
      you carried across verbatim, so you can quote and attribute them properly.
      It cannot search the web or any database. It cannot detect paraphrase, translation, or
      restructured ideas — all of which still require citation. A clean result here means only
      "no verbatim overlap with the text you gave me." It is not a certificate of originality
      and must not be presented as one.
      If you used someone else's words or ideas, quote and cite them. That is the whole job this tool exists to help with.

      How the results are produced
      
Methodology, scoring and limitations

      
AI Text Sanitizer uses transparent text-processing rules and editorial heuristics. Each result is tied to a detectable text pattern or a measurable document feature.

    

    

      

        1. Text cleanup logic
        
The sanitizer scans for selected invisible Unicode characters, unusual spacing, typographic characters and formatting residue. Enabled rules normalize or remove only the character classes described in the cleanup settings. The output is compared with the input so users can inspect what changed.

      

      

        2. Style review logic
        
Style review applies a documented ruleset to vocabulary, phrasing, openings, transitions, formatting, sentence patterns and specificity. Findings are rule matches and editorial signals. They are prompts for human review, not proof that a person or an AI system wrote the text.

      

      

        3. Voice match logic
        
Voice Match measures observable writing characteristics such as sentence and paragraph length, contractions, pronoun use, passive constructions, adverbs, reading level and rhythm. Comparisons describe similarity across these measurements. They do not establish authorship.

      

      

        4. Source overlap logic
        
Source Overlap compares the draft with text supplied by the user and identifies matching passages. It helps locate wording that may need quotation or citation. It does not search the web, check every published source, or make a legal determination about plagiarism.

      

      

        5. Publish check logic
        
Publish Check looks for detectable placeholders, unsupported numerical claims, structural issues and configured keyword or document checks. A clear result means no configured blocker was found. It does not independently verify facts, sources, permissions or regulatory compliance.

      

      

        6. Understanding scores and findings
        
Scores summarize the rules and measurements implemented in this version. A higher or lower score reflects the selected checks, their weights and the text supplied. It is not an AI probability, plagiarism percentage, quality guarantee or prediction of search-engine performance.

      

      

        7. Privacy and processing
        
Text processing runs locally in the browser. The tool does not upload draft text to a remote analysis service. If the optional voice profile is saved, the application stores derived measurements in browser storage rather than the original writing samples.

      

      

        8. Known limitations
        
Rule-based checks can produce false positives and miss patterns outside their rule definitions. Language, genre, discipline and context affect how a finding should be interpreted. Review important edits manually, especially in legal, financial, medical, technical and regulated content.

      

    

    
Editorial principle: use the findings to improve clarity, accuracy, attribution and individual voice. Do not use the tool to chase AI-detector scores. AI detectors can misclassify human writing and should not be treated as reliable authorship evidence.
